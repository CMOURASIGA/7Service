# 7Service

Sistema de gestão interna de acessos da Consult Services.

O 7Service é a plataforma administrativa interna responsável pela gestão central de clientes, usuários, produtos, licenciamento, acessos, convites, provisionamento e auditoria do ecossistema 7.

## Produtos iniciais

- 7Commander
- 7Finance
- 7Eventos
- CRM Flow
- 7Legal
- futuros produtos cadastrados no catálogo

## 7HUB

O 7Service será a origem administrativa de identidade e autorização para o futuro 7HUB. O 7HUB será voltado ao usuário final e apresentará somente os produtos aos quais o usuário possui acesso, sem assumir responsabilidades administrativas do 7Service.
